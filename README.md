# jarvis

Personal projects.

- [`card-scanner/`](card-scanner/): a free trading card scanner and collection tracker for
  Pokémon, One Piece, Magic: The Gathering, Marvel, Yu-Gi-Oh! and Lorcana cards. It runs in the phone browser and
  can be installed to the home screen. See its [README](card-scanner/README.md).
- [`mythbound/`](mythbound/): Mythbound, a dark-fantasy 3D action RPG for the browser (PC and phone) with classes,
  subclasses, races, roles, spells and six boss trials. See its [README](mythbound/README.md).
- [`beyond-the-walls/`](beyond-the-walls/): Beyond the Walls, a Roblox game. So far it has the main menu. See its
  [README](beyond-the-walls/README.md).
